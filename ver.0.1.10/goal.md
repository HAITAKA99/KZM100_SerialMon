# 開発指示書 - Web Serial Monitor

## 背景
今回の開発プロジェクト「Web Serial Monitor」の開発背景を説明する。
超音波風向風速計(KZM100A/KZM100LR 以下かざみん) は計測した情報をシリアル通信で外部に出力する。情報はプレーンテキストであり視認性がわるい。また、受信にはシリアル通信ソフトウェアが必要でありユーザーが事前にインストールと設定をする必要がある。今回開発する「Web Serial Monitor」はウェブブラウザ上で動作するリッチな計測コンソールをユーザに提供する。ユーザーはパソコンまたはスマートフォンにかざみんを接続し、ブラウザを開くだけで計測画面を見ることができる。

## 機能概要
- ブラウザーからパソコン、スマートフォン、タブレットに接続されているかざみんと直接シリアル接続する
- かざみんから送られてくるデータを受信する
- 受信したデータをリアルタイムにダッシュボードに表示
- 簡単な操作性

## データ受信機能詳細
- ブラウザーからデバイスに接続されているかざみんと直接シリアル接続する(Web Serial API を使用)
- かざみんからのデータを受信する。なお、受信データの仕様は下記
   - ボーレートは9600bps固定
   - 先頭から風速、風向、気温（摂氏）
   - 範囲は風速(00.0～99.9)、風向(000～359)、気温(-20.0～+65.0)
   - フォーマットは桁数固定で、下記
      00.0[m/s],000,+00.0[CR/LF]
   - 受信間隔は1[s]固定（かざみんから１秒おきに出力）
   - かざみんが出力する風速の単位は[m/s]固定
- シリアル接続の接続/切断ボタン
- 接続するシリアルポートを選択できること
## CSVデータ出力機能
- 保持している受信データ（最大７日間）を全てをCSV出力する機能
- 受信データにはタイムスタンプが含まれていること
## 受信コンソール機能
- かざみんからの受信データをシンプルに表示する受信コンソール画面を搭載すること
- 受信したタイムスタンプも表示すること
- データの値に関わらず画面上の桁数、長さが揃っていて見やすいこと
- 計測エラーデータ(99.9[m/s])のときは、表示色を変えること)
- データ受信の度に自動でスクロールし、最新のデータを最下部に表示すること
- 最大200件のデータをスクロールによって確認できること
## 風向メーター詳細
- リアルタイムに動作する風向メーター
- 中央に方位を表す大きな凹四角形型の針を配置すること
- 針の回転はなめらかに行うこと
- 0度が北、90度が東、180度が南、270度が西を表す。角度と方位を適宜配置すること
- 計測エラーデータ(99.9[m/s])のときは、エラーであることがわかる表示をすること
## 風速メーター詳細
- リアルタイムに動作する風速メーター
- 計測エラーデータ(99.9[m/s])のときは、エラーであることがわかる表示をすること
- 時間軸グラフの風速縦軸スケールの変更に合わせてスケールを変更すること
## 温度計詳細
- リアルタイムに動作する温度計
- 0℃と25℃の位置がわかるデザイン
- 華氏温度を小さく表示
## 時間軸グラフ詳細
- 風向、風速、気温を同時に表示する横軸が時間軸のグラフ
- グラフの時間スケールは10分間、1時間、6時間、24時間、7日間から選択でき、選択された時間で横軸スケールは固定する
- グラフの右端が現在時刻、左端が指定された時間スケール分の過去の時刻である
- 風速の縦軸スケールは5[m/s]、10[m/s]、20[m/s]、30[m/s]から選択できる
- 風向の縦軸は下端が0度、上端が359度
- 気温の縦軸スケールは-10℃～+50℃[default]と-20℃～+65℃[max]から選択できる
- 風速と気温のチャート表示はなめらかに繋がるラインチャートとする
- 風向は点をプロットしラインで繋がない
- 1秒毎に受信した最新データを都度時間軸グラフの右端に表示する
- 時間軸がスクロールしない間、右端のプロットは常に最新の受信データに置き換わる。
- グラフ上に表示するデータ数は指定されている時間スケールに関わらず600個に固定とする。
- データ数が600個に満たない場合、そのデータは描画対象外とする。
- 指定されている時間スケールが10分の場合は10分間のデータは全てグラフ上に表示する(10min x 60s = 600)
- 指定されている時間スケールが10分より大きい場合は全ての受信データを表示できない。その場合はスケール時間を600で割った時間間隔(例えばスケール時間が24時間の場合は144秒間隔)で時間軸をスクロールしデータをプロットしていく。
- 右端のデータを除きプロットされるデータはスクロール間隔時間中に受信したデータの中央値および最大値、最小値とする。例えばスケール時間が24時間の場合は直近144秒間の間に受信したデータの平均値を算出し、スクロール時に右端から２番目のデータとしてプロットする。
- データ平均化の際は計測エラーデータ時の風速と風向データは平均化の対象に含めない。なお温度データには計測エラーは無い
- 風速データと気温データの平均化の手法は算術平均とする
- 風向データ（角度データ）の平均化は算術平均が使えないためベクトルに変換してから平均を求めること
## その他機能詳細
- トップにタイトルを表示「かざみんリアルタイムモニター」
- バージョン情報をタイトルの横に付ける。初期バージョンは ver.0.1.0
- 24H表示デジタル時計を付ける
- 最下部にかざみん公式ホームページへのリンクとロゴ表示
## その他の実装上の留意点
- Web Serial API をサポートするほとんどのプラットフォーム、ブラウザで動作するよう留意
- スマートフォンのような小さなディスプレイからデスクトップの大画面まで柔軟に対応できるフレキシブルな画面デザインとする
- 直観的で視認性に優れた現代的デザインとすること
- １年以上の長期間にわたって連続して安定動作すること。ブラウザの資源枯渇に注意すること。
- インターネットに接続されていない環境でも動作すること
- タブを分ければ複数のかざみんからの同時受信が可能なこと
- かざみんは計測エラーを検知した場合、風速の値を99.9[m/s]に固定して送信する。これを検知し、エラーデータとして適切な処理をすること。
